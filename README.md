# PhotoPelangi

### Creative Image Editing & Graphic Design Workspace

**PhotoPelangi adalah aplikasi pengolah gambar dan desain grafis dari [Kios Pelangi](https://kiospelangi.com)** — dirancang untuk menghadirkan pengalaman editing visual yang cepat, fleksibel, dan efisien dalam satu workspace kreatif.

Dibangun menggunakan **Rust**, PhotoPelangi menggabungkan performa native, kemampuan pengolahan gambar, serta berbagai fitur desain dalam aplikasi desktop yang ringan dan berjalan secara offline.

[![GitHub](https://img.shields.io/badge/GitHub-lutfipelangi%2Fphotopelangi-blue?logo=github)](https://github.com/lutfipelangi/photopelangi)
[![Website](https://img.shields.io/badge/Website-kiospelangi.com-orange)](https://kiospelangi.com)

</div>

## ✨ Filosofi & Visi Produk

PhotoPelangi dikembangkan dengan satu tujuan: menghadirkan perangkat kerja kreatif yang powerful, mudah diakses, dan tidak bergantung pada layanan cloud maupun model berlangganan.

Kami percaya bahwa perangkat lunak kreatif seharusnya memberikan kebebasan kepada penggunanya untuk bekerja, bereksperimen, dan menghasilkan karya tanpa hambatan yang tidak perlu.

Dengan pendekatan native desktop dan teknologi Rust, PhotoPelangi berfokus pada tiga prinsip utama:

- **Performance First** — mengutamakan kecepatan, efisiensi sumber daya, dan responsivitas aplikasi.
- **Creative Freedom** — menyediakan berbagai tools untuk kebutuhan editing gambar dan desain grafis.
- **Privacy by Design** — pekerjaan dan proses editing dapat dilakukan secara lokal tanpa harus mengunggah gambar ke layanan cloud.

## 🚀 Fitur Utama

### Advanced Image Editing
Berbagai fitur editing untuk mendukung alur kerja kreatif dan pengolahan gambar:

- **Layers & Layer Management** — mengatur elemen desain secara terstruktur.
- **Masks** — mengontrol area tampilan dan pengolahan gambar.
- **Adjustment Layers** — melakukan penyesuaian visual secara terpisah.
- **Layer Styles** — memberikan efek dan tampilan pada elemen desain.
- **Type & Text Tools** — menambahkan dan mengolah elemen tipografi.
- **Vector Tools** — mendukung pembuatan dan pengolahan elemen berbasis vektor.
- **Brushes** — menyediakan tools untuk kebutuhan menggambar dan editing.
- **PSD Compatibility** — mendukung pembacaan file Adobe Photoshop PSD.

### ⚡ Native Performance
Dikembangkan menggunakan bahasa pemrograman **Rust** untuk menghadirkan aplikasi desktop native yang cepat, ringan, dan responsif.

### 🔒 Offline & Privacy-Focused
PhotoPelangi dirancang agar dapat digunakan tanpa koneksi internet. Proses editing berlangsung secara lokal sehingga pengguna memiliki kendali lebih besar atas file dan pekerjaan mereka.

### 💚 Free to Use
PhotoPelangi dapat digunakan secara gratis tanpa biaya langganan.

## 🔐 Privacy & User Experience

PhotoPelangi mengutamakan pengalaman kerja yang mandiri dan berorientasi pada privasi.

- Tidak memerlukan akun untuk menjalankan aplikasi.
- Tidak memerlukan koneksi internet untuk proses editing utama.
- Pengolahan gambar dilakukan secara lokal.
- Tidak menggunakan model berlangganan.

*Catatan: Pernyataan ini menjelaskan rancangan penggunaan offline aplikasi, bukan hasil audit independen terhadap seluruh komponen atau dependensi.*
