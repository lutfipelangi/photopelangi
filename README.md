# PhotoPelangi

**PhotoPelangi adalah PhotoShop dari [kiospelangi.com](https://kiospelangi.com)** — aplikasi pengolah gambar dan desain grafis berbasis Rust yang cepat, ringan, dan berjalan penuh secara offline.

[![GitHub](https://img.shields.io/badge/GitHub-lutfipelangi%2Fphotopelangi-blue?logo=github)](https://github.com/lutfipelangi/photopelangi)
[![Website](https://img.shields.io/badge/Website-kiospelangi.com-orange)](https://kiospelangi.com)

</div>

---

### Fitur Utama
- **Editing Lengkap:** Mendukung *Layers*, *Masks*, *Adjustment Layers*, *Layer Styles*, *Type/Teks*, *Vectors*, *Brushes*, serta membaca file **PSD**.
- **Performa Tinggi:** Dibangun murni dengan bahasa pemrograman **Rust** sehingga ringan dan responsif.
- **100% Offline & Gratis:** Bisa digunakan langsung tanpa koneksi internet maupun biaya langganan.
